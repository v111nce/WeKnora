# WeKnora 界面修改 Mia 提示词

本目录中的文件用于通过 WeKnora 管理界面，手动更新“留学问问”智能体的 Mia 身份提示词。

提示词文件都是可以直接全选复制的完整内容。不要把本 README 的说明文字粘贴到提示词输入框中。

## 一、打开智能体编辑页面

1. 在浏览器中登录需要修改的 WeKnora 环境。
2. 点击左侧导航栏中的“智能体”。
3. 在智能体列表中找到名称为“留学问问”的智能体。
4. 点击“留学问问”右侧的“编辑”按钮或编辑图标。
5. 在编辑窗口左侧或顶部选择“提示词配置”。
6. 确认当前编辑的是“留学问问”，不要修改内置智能体或其他同名测试智能体。

修改过程中不要点击“恢复默认”或切换智能体类型。完成下面三个区域后，再统一点击“保存”。

## 二、修改系统提示词

1. 在“提示词配置”中选择“系统提示词”。
2. 打开本目录下的 `01-system-prompt.txt`。
3. 在文件中执行全选和复制：macOS 使用 `Command+A`、`Command+C`，Windows 使用 `Ctrl+A`、`Ctrl+C`。
4. 回到 WeKnora 的“系统提示词”输入框。
5. 点击输入框，然后全选输入框中的原内容。
6. 粘贴 `01-system-prompt.txt` 的完整内容，覆盖原系统提示词。
7. 确认输入框开头是 `### Role`，靠近末尾能看到 `### Canonical Identity (STUDY_ABROAD_MIA_OVERLAY_V1)`。

`01-system-prompt.txt` 保留了测试服务器现有的检索、画像、隐私和回答规则，只替换了存在冲突的公开身份规则。

## 三、修改意图提示词

1. 在“提示词配置”中选择“意图提示词”。
2. 界面会显示多个意图切换按钮。每次选择一个意图，再粘贴对应文件的完整内容。
3. 点击意图对应的输入框，全选原内容并覆盖粘贴。
4. 按照下面的对应关系逐个完成，不能只修改“问候回复”：

| 中文界面中的意图分类 | 保留英文名称的复制文件 |
| --- | --- |
| 问候回复 | `02-intent-prompts/问候回复（Greeting Response）.txt` |
| 闲聊回复 | `02-intent-prompts/闲聊回复（Chitchat Response）.txt` |
| 追问回复 | `02-intent-prompts/追问回复（Follow-up Response）.txt` |
| 图片分析回复 | `02-intent-prompts/图片分析回复（Image Analysis Response）.txt` |
| 总结回复 | `02-intent-prompts/总结回复（Summarize Response）.txt` |
| 网络搜索不可用回复 | `02-intent-prompts/网络搜索不可用回复（Web Search Unavailable Response）.txt` |
| 文档分析回复 | `02-intent-prompts/文档分析回复（Document Analysis Response）.txt` |

每修改完一个意图，先切换到另一个意图再继续。切换后返回检查一次，确认刚才粘贴的内容仍然存在，并且开头是：

```text
### Canonical Identity (STUDY_ABROAD_MIA_OVERLAY_V1)
```

不要删除文件中已有的 `{{language}}`、`{{current_time}}` 等占位符。

## 四、修改检索兜底提示词

1. 在“提示词配置”中选择“检索兜底”或“兜底策略”。
2. 将兜底策略选择为“模型回答”，不要选择“固定回复”。
3. 找到“兜底提示词”输入框。
4. 打开本目录下的 `03-fallback-prompt.txt`，全选并复制完整内容。
5. 回到“兜底提示词”输入框，全选原内容并覆盖粘贴。
6. 确认输入框开头是 `### Canonical Identity (STUDY_ABROAD_MIA_OVERLAY_V1)`。
7. 确认输入框末尾仍然包含 `User question: {{query}}`。

不要删除 `{{language}}` 和 `{{query}}` 占位符，否则保存校验或实际回答可能异常。

## 五、保存

1. 再次确认当前智能体名称是“留学问问”。
2. 确认系统提示词、7 个意图提示词、检索兜底提示词都已修改。
3. 点击编辑窗口底部的“保存”或“确定”。
4. 等待界面提示保存成功后再关闭编辑窗口。

保存动作会调用 WeKnora Agent API，并把配置写入数据库，不需要重启或重新构建 Docker。

## 六、验证效果

1. 返回聊天页面。
2. 新建一个会话，避免旧会话上下文影响测试。
3. 选择“留学问问”智能体。
4. 依次发送下面的问题：

```text
你是谁
你是什么模型
你是哪个公司开发的
你是腾讯开发的吗
```

“你是谁”的预期回复是：

```text
我是留学问问的 AI 留学顾问 Mia，主要帮助你梳理留学方向、申请准备和下一步安排。
```

询问模型、供应商或开发团队时，预期回复是：

```text
我是留学问问的 AI 留学顾问 Mia。我不会提供或猜测底层模型、技术供应商或团队信息；可以继续帮你咨询留学问题。
```

回复中不应出现 `WeKnora`、`Tencent`、“腾讯开发”或具体底层模型名称。
